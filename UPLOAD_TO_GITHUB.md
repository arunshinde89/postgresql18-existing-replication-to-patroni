# Upload from Windows PowerShell

Extract the ZIP. Open PowerShell in the extracted `postgresql18-existing-replication-to-patroni` folder.

## Option A — GitHub CLI (create a new repository)

Requires `git`, `gh`, and a one-time `gh auth login`.

```powershell
git init -b main
git add .
git commit -m "Document PostgreSQL 18 native replication to Patroni migration"
gh repo create postgresql18-existing-replication-to-patroni --public --source=. --remote=origin --push
```

## Option B — Git without GitHub CLI

First create an **empty repository** of the same name on GitHub, without an autogenerated README/license. Then:

```powershell
git init -b main
git add .
git commit -m "Document PostgreSQL 18 native replication to Patroni migration"
git remote add origin https://github.com/YOUR-USERNAME/postgresql18-existing-replication-to-patroni.git
git push -u origin main
```

If `origin` already exists, use `git remote -v` before adding it. For an existing repository with unrelated commits, reconcile its history instead of force-pushing.

## Security check before publishing

```powershell
git status --short
git ls-files | Select-String -Pattern "private|pgpass|secret|backup"
```

Review any matches; never publish real passwords, `.pgpass` files, Patroni private YAML, database backups or data directories. Only example configurations are included in the ZIP.
